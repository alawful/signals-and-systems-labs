# CA7: symbolic and Simulink system models

This final group of exercises compares analytical and block-diagram approaches to continuous-time system response.

## Files

- `q1.slx` uses gains, summing blocks, transfer functions, a step input, and a scope to assemble a response model.
- `q21.slx`, `q22.slx`, and `q23.slx` are related Simulink variants that also use derivative blocks to compare system configurations.
- `q3.m` solves a second-order differential equation symbolically with initial conditions and plots it alongside the corresponding closed-form expression.

## Running notes

The MATLAB script requires Symbolic Math Toolbox, while the model files require Simulink. The original video and submission report are intentionally not included.

These are compact course exercises, not validated control-system designs. The short filenames follow the assignment numbering.
