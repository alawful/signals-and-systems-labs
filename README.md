# Signals and systems labs

This repository collects two of my MATLAB-based Signals and Systems assignments at the University of Tehran. I kept the related scripts and models together so the work can be read in context rather than as isolated files.

## What is included

- `ca5-frequency-coding/` explores frequency-based coding and decoding, signal construction, and related experiments.
- `ca6-signals-and-simulink/` includes MATLAB scripts and Simulink models for signal generation and differential-equation/system-response exercises.

The filenames follow the original assignment numbering. Submission PDFs and audio files were left out to avoid publishing student identifiers or redistributing media.

## Running the work

The `.m` files were written for MATLAB. The `.slx` files require Simulink. Some scripts were designed to be run in the order given by the assignment report, so they are not packaged as a single application.

## Scope

These are course labs, not a general signal-processing library. They show how I approached the assigned problems at the time, including a few rough edges that are normal in submitted coursework.
